# Sistema CRUD para importações da China

# Português: <br/> 
Sistema CRUD feito para estudos e aprofoundamento acerca da linguagem Python e suas aplicações no mercado. O banco de dados utilizado no sistema é o Oracle através do sqldeveloper. <br/>
<br/>
O objetivo principal desse CRUD é gerar um banco de dados com informações de fretes e produtos da China (em CNY) para converter em BRL armazenando seus dados conforme cotação (1 BRL = X CNY). <br/>
O sistema ainda está em desenvolvimento (WIP) e ainda vou construir o front-end além de efetuar uma busca aprofundada de possiveis erros.<br/>


# English: <br/>
A CRUD system developed for study purposes to deepen knowledge of Python and its real-world market applications. The project uses an Oracle database managed via SQL Developer.<br/>
<br/>
The main objective of this system is to manage a database of shipping and product information from China (in CNY), converting values to BRL based on a configurable exchange rate (1 BRL = X CNY).<br/>
This project is currently a Work In Progress (WIP). Future updates will include the development of a Front-end interface and comprehensive debugging.<br/>
